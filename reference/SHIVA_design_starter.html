02 · Universal Trait Semantics

The Four Trait Families

The visual language is built on four trait families. Every component must declare which family it belongs to. Each family has a canonical accent color and a render style.

Static static

intrinsic descriptors
render: gradient bars · nested shapes · geometric glyphs

Dynamic dynamic

movement, flow, energy
render: dashed flows · pulse · spring zigzag

Relational relational

direction, balance, proportion
render: balance lines · ratio bars · counter-arrows · rails

Vital vital

growth, decay, adaptation, entropy
render: growth bars · half-life ticks · morph arrows · noise dissolve

04 · Motion Vocabulary

Canonical Animation Kit

The entire motion vocabulary. Do not invent new keyframes. All animations respect prefers-reduced-motion and disable in print.

View keyframe source 
/* All keyframes — copy-paste vocabulary */
@keyframes dash    { to { stroke-dashoffset: -120; } }
@keyframes flow    { to { stroke-dashoffset: -2600; } }
@keyframes pulse   { 0%{opacity:.3} 50%{opacity:1} 100%{opacity:.3} }
@keyframes wobble  { 0%,100%{transform:translateX(0)} 50%{transform:translateX(4px)} }
@keyframes drift   { 0%,100%{transform:translate(0,0)} 50%{transform:translate(6px,-4px)} }
@keyframes jitter  { 0%,100%{transform:translate(0,0)} 50%{transform:translate(-1px,1px)} }
@keyframes spin    { from{transform:rotate(0deg)} to{transform:rotate(360deg)} }
@keyframes breathe { 0%,100%{transform:scale(1)} 50%{transform:scale(1.04)} }

/* MANDATORY accessibility wrapper */
@media (prefers-reduced-motion: reduce) {
  .anim-dash, .anim-pulse, .anim-wobble, .anim-drift,
  .anim-jitter, .anim-spin-slow, .anim-breathe {
    animation: none !important;
  }
}

07 · Container

The Capsule Pattern

Every standalone deliverable is a "capsule." Structure is fixed: kicker → heading → tag → body → details → figure → footer glyph.

Clinical Integrity Capsule

Pelvic Shape Ratio (R) — Reliability Sub-study

static sealed

Single-rater test–retest of the calibration-invariant pelvic shape ratio R across 29 lateral radiographs and 6 measurement sessions. Average-of-6 ICC reaches 0.815 (95% CI 0.60–0.90), with SEM 0.113 and MDC95 0.312.

Variance partition

~42% signal · 0% session drift · ~58% random error. FH landmarks ~2× noisier than S1 corners. Stability subset (SD < 0.20, n=10) reaches ICC_avg6 = 0.97.
